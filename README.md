# charlie-rs
Library for interacting with MBTA CharlieCards. Includes the ability to read fare information, card types, expiration date, and some location data.

We do not endorse or encourage evading fares on the MBTA, especially since there are detection methods in place that can track the use of forged or altered cards. This library is intended only for research purposes and as a way to learn more about how CharlieCards work.
