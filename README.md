# charlie-rs
Library for interacting with MBTA CharlieCards. Includes the ability to analyze fare value, card type, expiration date, and usage history.

It is strongly discouraged to use this tool to evade fares on the MBTA. This is especially true since there are detection methods in place that can track the use of forged or altered cards. Don't get in trouble! This library is intended only for research purposes and as a way to learn more about how CharlieCards.

For more info about how CharlieCards work and our reverse engineering process, check out [our talk at DEF CON 31](https://www.youtube.com/watch?v=1JT_lTfK69Q).
